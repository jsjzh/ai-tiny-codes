## 需求

1. 我想做一个应用，主要功能是，在日历上新建各种事项，然后日历上会有展示，然后根据事项的内容，自动生成图表
2. 用 vite react-ts 的模板生成项目，Tailwind shadcn，如果后面需要什么依赖酌情下载就好
3. 记得用 frontend-design

## 描述

分成四大部分，一步一步实现

### 日历

1. 首先，样式是个大日历，不是小小的组件，甚至可以占满一个屏幕的那种大小
2. 顶部增加年份和月份的显示，然后还要支持年份和月份的选择，最右边有一个今天的按钮，点击可以回到当前时间的月份
3. 日历的头部从周日到周六，每天都是一个块，右上角显示当天的日
4. 每个月显示的日要往前推一个星期 + N 天，N 的意思是为了让日历显示完整，向前补全到周日，向后补全到周六
   1. 然后非本月的日，那块的日文字颜色淡一些
5. 块原始色是白色，当前日子要有一个区分色
6. 双击某个块可以编辑（编辑弹窗见下面描述），选中一个按 shift 再选另一个可以按日期多选过去，然后在任何一个选中的右键，可以跳出操作列表，第一个是编辑，第二个是清空，点击编辑打开编辑弹窗，点击清空需要二次确认；按住 ctrl 一个个点选日期可以分别选中日期，在任何一个选中的右键，逻辑和 shift 选中一样（shift 和 ctrl 是 windows 的，记得也要加上对应苹果的按键）；另外再加一个操作方式，就是点击鼠标拖动，就会自动选择到鼠标划过的块，接下来右键的逻辑和 shift ctrl 一样
   1. 选中的块可以加个特殊的 border 颜色区分
