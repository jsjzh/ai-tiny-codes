## 主题（已完成）

目标：把颜色、字体、圆角、阴影、图表色板抽成 token，用 `data-theme` 切换，记住用户选择。默认仍是 Blueprint。

候选风格：

1. **Blueprint / 制图台（当前）**
   - 冷白纸、靛蓝、信号橙、细线网格、无圆角无阴影。
   - 数字用等宽字体，信息密度高，适合记录和对照。

2. **Warm Editorial / 暖纸编辑部**
   - 燕麦纸底、炭黑文字、陶土红 / 苔藓绿点缀。
   - 标题用衬线体，正文无衬线；更柔和、有阅读感。
   - 适合“日记 / 复盘”气质，图表色板偏暖。

3. **Night Ops / 夜航仪表盘**
   - 近黑底、石墨面板、青绿 / 电光蓝强调色。
   - 高对比、数字醒目，适合晚间记录和长期趋势。
   - 网格线更暗，图表用发光感但避免霓虹过量。

4. **Botanical / 苔原笔记**
   - 鼠尾草绿、砂岩、奶油白、黏土色。
   - 低饱和、自然、安静；圆角可以略微放大。
   - 适合健康 / 体重 / 饮食场景。

5. **Swiss Signal / 瑞士信号**
   - 纯白、黑、红、钴蓝；粗分割线、强字号层级。
   - 极简、海报感，图表用少量高饱和色。
   - 适合强调数字和目标，不追求柔和。
