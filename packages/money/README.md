## 攒钱计划计算器

输入「已有存款 / 每年攒多少 / 年化收益率 / 目标金额 / 开始日期」，逐年算出攒钱进度，并给出达标需要多久。

### 运行

```bash
# 仓库根目录
pnpm money:calculate

# 或进入本包
pnpm --filter @ai-tiny-codes/money calculate
```

### 输入

用 `@inquirer/prompts` 交互提问，非法值会重新提示：

| 项 | 说明 |
| --- | --- |
| 当前已有存款 | 元，≥0，默认 0 |
| 每年攒多少 | 元，≥0，默认 100000 |
| 年化收益率 | **输入 `2` 表示 2%**，≥0，默认 2 |
| 目标金额 | 元，>0，默认 2500000 |
| 开始日期 | `YYYY-MM-DD`，默认今天 |

### 计算口径

- **年初存入**：每年年初先存入当年的钱，再计息
- 年利息 = 年初余额（含当年存入）× 年化
- 年末总额 = 年初余额 × (1 + 年化)
- **精确到月**：年内利息按月线性累积，`第 m 月余额 = 年初余额 × (1 + 年化 × m/12)`，取第一个 ≥ 目标的月份为达标点（该模型下满年结果与纯年复利一致）
- 初始存款同样参与计息；若初始存款已达目标，直接提示「已达标，无需再存」
- 年化为 0 且不再存入时，提示无法达标

### 输出

用 `cli-table3` 输出逐年明细：

```
年份 | 当年利息 | 当年存入 | 年末总额
```

并给出结论：需要多久（X 年 Y 个月）、达成年月、最终金额、总投入本金（初始存款 + 年存 × 年数）、总利息收益。

### 记忆

上次输入保存在 `~/.ai-tiny-codes/money/last-input.json`，下次运行自动作为默认值。

### 依赖

`@inquirer/prompts`、`cli-table3` 在仓库根 `package.json` 声明；`@ai-tiny-codes/utils` 为本仓库 workspace 公用包（包名 `workspace:*` 链接）。
